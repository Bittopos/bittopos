ACERCA DE

Bittopos Web

Esta es una interfaz web experimental para el modelo actual de Bittopos. Funciona localmente en el navegador y no se conecta todavía con el núcleo Rust ni con los archivos de tu dispositivo.

  • Importa el JSON del workspace y las definiciones de recursos TOML.
  • Los cambios se guardan en el almacenamiento de este navegador.
  • Exporta el workspace JSON y los recursos TOML para mover los archivos manualmente.

No sustituye una copia de seguridad. Exporta los cambios antes de borrar los datos del navegador.
